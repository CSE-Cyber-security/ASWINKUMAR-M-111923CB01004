# Week 3 GitHub Task: Fibonacci Series

## Objective
Write a Python program to display the Fibonacci series for the number of terms entered by the user.

## Requirements
- Python 3.9 or later
- No external packages required

## How to run
1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   python fibonacci.py
   ```

4. Enter the number of terms when prompted.

## Example output
```text
Enter the number of terms: 8
Fibonacci series:
0 1 1 2 3 5 8 13
```

## How it works
The program starts with `0` and `1`. Each next term is the sum of the previous two terms. It also handles invalid input and negative values.

## Test cases
| Input | Expected series |
|---:|---|
| 0 | Empty series |
| 1 | `0` |
| 2 | `0 1` |
| 8 | `0 1 1 2 3 5 8 13` |
