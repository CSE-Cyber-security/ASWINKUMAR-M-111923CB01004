# Week 2 - Factorial in Python

## Problem
Write a Python program to find the factorial of a given number.

## How to run
1. Install Python 3 if it is not already installed.
2. Open a terminal or command prompt in this folder.
3. Run:

   ```bash
   python factorial.py
   ```

   On some systems, use `python3 factorial.py`.

4. Enter a non-negative integer when prompted.

## Example
```text
Enter a number: 5
Factorial of 5 = 120
```

## Notes
- The factorial of `0` is `1`.
- Factorial is not defined for negative integers.
